# Japita logo exploration

Ten original logo concepts generated with the built-in image generation tool on 2026-10-18. Each PNG preserves its original alpha transparency. The user selected their attached JP symbol combined with option 04's lettering; this combination is now applied to the app and mockup. The selected source image is preserved as `selected-jp-symbol-reference.png`; its final edit prompt is in [selected-logo-prompt.txt](selected-logo-prompt.txt). The canonical result is [japita-logo-jp.png](../../../mockup/assets/japita-logo-jp.png).

The palette and visual direction follow the app's Ajitama style: warm charcoal, yolk yellow, chili red, substantial lettering, and flat illustrations. The files are concept artwork, not vector masters.
